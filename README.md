# Bimmer Cockpit – website

The one-page website for **Bimmer Cockpit**: climate control, live MS43 gauges, engine logging and on-board diagnosis for MS43-powered BMW E-series cars (an ESP32 module behind the dash and an Android app on the head unit).

Served by GitHub Pages at **https://oshanrube.github.io/bimmer-cockpit-docs/**:

- `index.html`: the website
- `privacy.html`: the app's privacy policy (the URL for Google Play)
- `screenshots/`: the app's screens, rendered from the app with sample data

Not affiliated with or endorsed by BMW AG.
